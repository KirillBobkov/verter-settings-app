# Как оператору подключить интерфейс

## Что нужно

1. Файл кредов `ui-<имя>.creds` — выдаёт администратор хаба. Выдача описана
   в приватном репозитории `nats-hub` (`auth/auth-commands.sh add-operator <имя>`),
   сами креды передаются по защищённому каналу (менеджер паролей, не мессенджер).
2. Адрес хаба — уже вшит в `public/config.json` сайта.

## Подключение

1. Откройте сайт (GitHub Pages).
2. Перейдите на «Настройки», вставьте содержимое файла кредов целиком
   (оба блока: `-----BEGIN NATS USER JWT-----…` и `-------BEGIN USER SEED-------…`).
3. Нажмите «Сохранить и подключиться».
4. Креды хранятся только в localStorage вашего браузера. Кнопка «Забыть креды
   и адрес» удаляет их полностью.

## Если креды истекли

Настройки показывают срок действия. Заблаговременно (за 3 дня) запросите новые
у администратора — старые перестают работать в указанную дату.

## Безопасность

- Никому не пересылайте файл кредов: он даёт управление роботом.
- Кнопка «Стоп» — программная, она не заменяет аппаратный аварийный выключатель.
- Ручное управление не включает автоматический объезд препятствий.
- Если вкладка ушла в фон или потеряла фокус — управление с неё прекращается;
  робот останавливается сам не позднее чем через 1 с (серверный lease).
