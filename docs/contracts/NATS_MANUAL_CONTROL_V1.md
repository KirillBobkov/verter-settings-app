# Ручное управление через NATS

Контракт запросов, ограничений скорости, lease, stop и состояния находится в
[разделе 8 основного контракта](NATS_CONTRACTS_V1.md#8-ручное-управление-через-nats).

Шаг кнопок: 0,01 м/с вперёд/назад и 0,05 рад/с влево/вправо. Стрелки клавиатуры
работают при фокусе окна управления, пробел — stop. Отображение скорости в кнопках
берётся из одометрии; заданная скорость показывается отдельно. Ручное управление
не включает автоматический объезд препятствий.

Код backend — `services/nats_bridge/robot_nats/motion.py`, кнопок —
`services/nats_bridge/static/drive.js`. [Устройство тестового веба](../services/nats_bridge/README.md).
Поле `cmd_vel.contract` машинного каталога указывает на этот документ.


## Панель ручного управления в дополнительных окнах

Окна камеры (8089) и лидара (8090) содержат компактную панель сверху.
Щёлкните по панели или перейдите в неё клавишей Tab: рамка подсвечивается.
Стрелки работают только внутри панели; пробел — stop. Один нажим меняет скорость
на 0,01 м/с или 0,05 рад/с. Удержание клавиши не повторяет шаг.
В кнопках показывается фактическая скорость по одометрии, заданная — рядом.
Потеря фокуса окна/скрытие вкладки прекращает управление из него; при закрытии
срабатывает существующий lease backend. Открытие окна ничего не запускает.
У всех окон общий backend: активная сессия другой страницы блокирует стрелки.

Общий код: `services/nats_bridge/static/drive.js`, `drive-widget.js`,
`drive-widget.css`; HTTP-прокси: `services/nats_bridge/robot_nats/drive_widget.py`.
На обоих портах `GET /api/drive` и `POST /api/command` проксируются в локальный
NATS bridge (127.0.0.1, порт `config/nats/bridge.json:web_port`, по умолчанию 8088).
POST принимает только `cmd_vel.status`, `cmd_vel.set`, `cmd_vel.keepalive`,
`cmd_vel.stop` в существующем JSON-конверте. ID, время и TTL сохраняются;
повторной отправки при ошибке нет. Ответ bridge передаётся без изменения.
Ошибка соединения возвращает HTTP 503, неверное действие/JSON — 400,
неверный Content-Type — 415, тело свыше 16 КиБ — 413.
Проверки Host/Origin остаются на сервисе окна. NATS ACL камеры и лидара
не расширяются: команды публикует действующий backend управления.
Для SSH достаточно порта соответствующего окна; проброс 8088 не требуется.
При недоступном bridge просмотр работает, управление недоступно.
